# Daniel Maina (danitech) — Developer Portfolio

A modern, responsive, cyber-terminal styled developer portfolio engineered with React 19 and Vite. Features interactive spotlight cards, a real-time CLI terminal sandbox, multi-platform architecture showcases, and smooth ambient animations.

---

## ✨ Features

- **Interactive Spotlight Cards**: Cursor-tracking radial glow (`--mouse-x`, `--mouse-y`) that dynamically illuminates card borders and surfaces.
- **Hero CLI Sandbox**: Interactive simulated terminal where visitors can execute commands (`whoami`, `bio`, `skills`, `projects`, `status`, `contact`).
- **Multi-Platform Project Showcases**:
  - **ShuleBase**: Educational ecosystem with interactive edition tabs (*Web Edition*, *JavaFX Desktop*, *PyQt5 Desktop*) and one-click demo credentials access.
  - **DataPilot**: AI-assisted workflow and data automation platform with direct portal launch.
  - **Apex Logistics**: Enterprise logistics, telemetry fleet tracking, statutory payroll, double-entry financial ledger, and warehouse inventory ERP platform.
- **Dynamic Architecture Spec Drawer**: Expandable system breakdowns for each project detailing tech stack tiers, data layers, and security architecture.
- **Branded Ambient Theme**: Floating gradient mesh, cyber grid overlay, and faint logo watermarks in an obsidian dark aesthetic.
- **Interactive `.env` Contact Card**: One-click clipboard copy for GitHub, LinkedIn, Facebook, Email, and Location with system toast alerts.
- **Direct PDF CV Download**: Direct access and download for `Daniel_Maina_CV.pdf`.
- **Full Accessibility**: Built-in support for `prefers-reduced-motion`.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm, yarn, or pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/danitech887/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Lint the code**:
   ```bash
   npm run lint
   ```

## 🌐 Deploy to Vercel

This repository is pre-configured for seamless, zero-config deployment on **[Vercel](https://vercel.com/)**:

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/danitech887/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
2. Log into your [Vercel Dashboard](https://vercel.com/new).
3. Click **"Add New..."** -> **"Project"** and import your GitHub repository.
4. Vercel will automatically detect the **Vite** preset:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"** — your portfolio will be live in seconds!
